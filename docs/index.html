SUPPORTED BROWSER PROFILE

Explicit files.
Conservative corrections.

The browser reads dark, solid circle/rectangle/obround flashes with absolute leading-zero Gerber format, declared MM/IN units and complete XY flash coordinates. Drill input uses explicit METRIC/INCH units, tool definitions and absolute decimal XY round hits.

Tracks, regions, macros, clear polarity, rotations, mirrors, scaling, repeats, slots and integer drill coordinates are refused by the browser. The Python CLI can parse a broader explicit Gerber profile. Slots and routed drills are refused by both; no corrected file is produced.

Use the CLI for real exported fabrication files

python -m pip install .
drill-origin-rescue copper.gbr drill.drl --out review-draft

Supported Gerber flashes only. No guessed units or coordinate formats. Inputs and existing output folders are protected.
